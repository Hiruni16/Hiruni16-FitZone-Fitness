# FitZone Fitness Center Website

## Project Overview

FitZone Fitness Center Website is a responsive web application developed to provide an online platform for a fitness center. The system allows customers to explore fitness programs, view workout and meal plan information, register for programs, book appointments, and submit inquiries.

It also includes separate Admin and Staff functionalities to manage customer information, staff details, appointments, program registrations, and customer queries.

## Features

### Customer Features
- View the Home, About Us, Services, and Contact pages
- Explore fitness programs and membership details
- View workout plans and healthy meal plans
- Read customer reviews
- Register and log in to the system
- Register for fitness programs
- Book appointments
- Submit inquiries through the contact form

### Admin Features
- Admin login
- Add new staff members
- Update staff details
- Delete staff records
- View customer information
- View customer inquiries
- View appointment details
- View program registrations

### Staff Features
- Staff login
- Access the staff dashboard
- View customer inquiries
- View appointment details

## Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and responsive design
- **JavaScript** – Interactive elements and form validation
- **PHP** – Backend development and server-side processing
- **MySQL** – Database management
- **XAMPP** – Local development environment

## Database

The application uses MySQL to store and manage information, including:

- Admin details
- Staff details
- Customer details
- Program registrations
- Appointment records
- Customer queries

## System Architecture

The application follows a basic three-layer web architecture:

1. **Frontend:** HTML, CSS, and JavaScript provide the user interface.
2. **Backend:** PHP handles authentication, form submissions, and database operations.
3. **Database:** MySQL stores and retrieves application data.
